# Audience Discovery & Influencer CRM

**Семантический поиск блогеров под вашу аудиторию — по смыслу контента, а не по хэштегам.**

Платформа инфлюенс-маркетинга: гибридный поиск авторов по базе собранных профилей и CRM для ведения сделок от первого касания до публикации.

## Возможности

- **Семантический поиск авторов.** Запрос свободным текстом («мамы 30+, интересуются скандинавским интерьером») превращается в релевантную выдачу: система понимает содержание постов и транскрипций видео, а не только подписи и теги.
- **Глубокие профили.** По каждому автору: тематика и категория, вовлечённость, география и языки аудитории, контакты для связи.
- **Умная аналитика.** Автоматическое обогащение профилей: тип блога, тематическая категория, демография, краткое резюме контента.
- **CRM для сделок.** Канбан, карточки авторов, история коммуникаций, файлы и договоры, реестр маркировки рекламы, аналитика кампаний.
- **Мультиплатформенность.** Instagram, Telegram — с единым профилем автора.

## Как это работает

1. Вы описываете продукт или аудиторию своими словами.
2. Поиск комбинирует векторное сходство контента, граф знаний и метрики вовлечённости — и ранжирует авторов по релевантности.
3. Подходящие авторы попадают в шортлист, затем в сделки: переписка, договор, маркировка, отчётность — всё в одном месте.

## Технологии

FastAPI · PostgreSQL · Qdrant · Neo4j · LLM-обогащение и экстракция · React
